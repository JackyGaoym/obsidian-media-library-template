# 媒体库使用说明

这套模板用一个文件夹统一保存图书、电视剧、电影、动漫和游戏，再通过属性与视图分类展示。示例条目均为虚构内容；正式使用前可以全部删除。

## 第一次使用

1. 使用桌面版 Obsidian 打开整个模板文件夹，不要只导入 `媒体库` 子文件夹。
2. 在「设置 → 第三方插件」中关闭安全模式，然后安装并启用 Dataview、Meta Bind、QuickAdd。Homepage、Douban、Style Settings 为推荐或可选插件。
3. 在 Dataview 设置中确认 `Enable JavaScript Queries` 已开启。
4. 在「设置 → 外观」安装 Border 主题，并启用 `media-library` CSS 片段。若不喜欢 Border，保留 CSS 片段也能使用主要功能。
5. 返回 [[媒体库/首页|媒体库首页]]。若首页尚未渲染，重启 Obsidian 或执行「重新加载应用」。

完整安装清单见仓库根目录的 `README.md` 与 `THIRD_PARTY.md`。

## 新增作品

从 [[媒体库/首页|媒体库首页]] 点击「新增作品」，再选择分类与录入方式。

### 手动新增

适用于任何来源，也是最稳定的录入方式：

- 标题必填；发行年份可以留空，文件名会使用「未知年份」。
- 图书、电视剧、动漫和游戏可直接维护阅读、观看或游玩进度。
- 没有封面、总页数或总集数不会影响条目创建，只会显示占位样式。
- 同名文件出现冲突时，优先保留已有文件，避免覆盖短评、进度与关系。

### 豆瓣导入

Douban 插件可导入图书、电影、电视剧和游戏。动漫使用影视搜索，导入后在详情页把 `media_type` 改为 `anime`。

豆瓣导入属于可选功能，网页结构或登录策略变化时可能失效。首次使用若插件要求登录，请在自己的 Obsidian 中完成；不要把 `.obsidian/plugins/obsidian-douban-plugin/data.json` 中的 Cookie、请求头或账号信息提交到公开仓库。

## 状态、评分与进度

- `status`：待体验、进行中、已完成、暂停、弃置。
- `rating`：个人评分，范围 0.5–5，支持半星；清除按钮会将评分恢复为空值。
- `source_rating`：外部社区评分，和个人评分分开保存。
- 图书使用 `current_page / page_count`。
- 电视剧与动漫使用 `current_episode / episode_count`。
- 游戏使用 `progress_percent`；拖动时实时预览，松手后才写入文件。

`favorite` 只表示个人收藏，不会改变状态或评分。

## 封面与横幅

- 作品封面：`媒体库/附件/封面/`
- 作品横幅：`媒体库/附件/横幅/`
- 合集或系列封面：`媒体库/合集/封面/`
- 合集或系列横幅：`媒体库/合集/横幅/`

建议素材规格：

| 用途 | 比例 | 推荐尺寸 | 最低建议 |
| --- | --- | --- | --- |
| 作品、合集或系列封面 | 2:3 竖版 | 1000 × 1500 px | 600 × 900 px |
| 作品、合集或系列横幅 | 16:9 横版 | 1920 × 1080 px | 1280 × 720 px |

- 比例比绝对尺寸更重要。封面不是 2:3 时，首页和分类卡片会居中裁切。
- 横幅会随窗口宽度裁切，主体尽量放在中部偏右，四周留出空间，避免被左侧标题区和渐变遮住。
- 优先使用 WebP 或 JPG；透明图片可以使用 PNG。建议封面不超过 1 MB、横幅不超过 2 MB。
- 文件名建议与作品或合集名称一致，方便在图片选择器中查找。

作品页会自动用封面生成模糊背景，所以横幅并不是必填项。需要更好的横向构图时，把 16:9 本地图片放入相应的「横幅」目录，再通过作品页或合集页的「选择横幅」控件设置。

我个人常用的素材来源：

- 影视剧、电影和动漫：[The Movie Database（TMDB）](https://www.themoviedb.org/)——封面选择 Poster，横幅选择 Backdrop。
- 游戏：[SteamGridDB](https://www.steamgriddb.com/)——封面选择接近 2:3 的竖版 Grid；Hero 通常更宽，作为横幅使用前先裁成 16:9。

这些网站并不是模板依赖。图片版权通常属于原权利人，请遵守来源网站条款，仅保存自己有权使用的素材；公开仓库不要直接收录下载的电影海报、剧照、图书封面或游戏美术。

## 系列、合集与相关作品

三种关系用途不同：

- `series`：某作品所属的单一系列，例如第一季、第二季、前传或续作；系列页按 `release_date` 排序。
- `collections`：主题合集，可以收录独立作品，也可以让一个完整系列归入合集；一个作品可加入多个合集。
- `related`：改编、衍生、相似或其他松散关系。

新建合集时，`collection_kind` 只使用两个值：

- `series`：系列。
- `collection`：合集。

相关作品是双向关系。请用作品页关系区里的「相关作品（双向）」控件添加或移除；直接在 Properties 中修改 `related` 只会改变当前文件，另一端不会同步。

## 文件与属性约定

所有作品都保存在 `媒体库/作品/`，不要再按类型移动文件。分类完全由 `media_type` 决定：

- `book`：图书
- `tv`：电视剧
- `movie`：电影
- `anime`：动漫
- `game`：游戏

核心字段：

| 字段 | 类型 | 用途 |
| --- | --- | --- |
| `note_type` | 文本 | 作品固定为 `media`，合集固定为 `media_collection` |
| `media_type` | 文本 | 五种媒体分类之一 |
| `title` | 文本 | 展示标题 |
| `cover` / `backdrop` | 链接或文本 | 本地封面与横幅 |
| `status` | 文本 | 当前状态 |
| `rating` | 数字 | 个人 0.5–5 分评分 |
| `added_at` | 日期 | 加入媒体库的日期 |
| `series` | 链接 | 单一系列归属 |
| `collections` | 链接列表 | 一个或多个合集归属 |
| `related` | 链接列表 | 双向相关作品 |

完整属性类型保存在 `.obsidian/types.json`。

## 删除示例数据

仓库内的作品、作者、工作室、出版社、评分与短评全部是虚构示例。确认模板能正常渲染后，可删除：

- `媒体库/作品/` 中全部 Markdown 文件；
- `媒体库/合集/` 中的「宇宙漫游」和「星际邮差系列」；
- `媒体库/附件/封面/` 与 `媒体库/合集/封面/` 中随附的 SVG 示例封面。

不要删除 `媒体库/模板/`、`媒体库/视图/`、分类页和首页。

## 备份与公开发布

Obsidian 笔记是本地文件，模板不会自动替你备份。建议用 Git、Obsidian Sync 或其他同步工具，但不要把同一个库交给多个同步工具同时接管。

公开发布自己的派生版本前至少检查：

- `.obsidian/workspace*.json`、`.trash/`、`.DS_Store` 已排除；
- 插件配置里没有 Cookie、Token、API Key、邮箱、账号或本地绝对路径；
- `媒体库/作品/`、附件、合集和截图中没有个人记录；
- 图片、字体、主题与插件没有被未经许可地打包分发。

## 常见问题

### 首页显示代码而不是卡片

确认 Dataview 已启用，并在其设置中打开 JavaScript Queries。之后重启 Obsidian。

### 评分、状态或关系控件不显示

确认 Meta Bind 已安装并启用。若插件刚升级，先执行「重新加载应用」。

### 「新增作品」按钮没有反应

确认 QuickAdd 已启用，而且 `.obsidian/plugins/quickadd/data.json` 仍存在。若手动重建了 QuickAdd 配置，需要同步修改 `媒体库/首页.md` 中调用的 choice ID。

### 首页没有自动打开

安装 Homepage，并确认首页路径为 `媒体库/首页`。这不影响模板其他功能，也可以手动把首页加入书签。

### 豆瓣导入失败

豆瓣功能依赖第三方网页与插件实现，不属于模板核心能力。先确认 Douban 插件版本与登录状态；仍失败时使用手动模板录入。
