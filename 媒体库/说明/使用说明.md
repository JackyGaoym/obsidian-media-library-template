# 媒体库使用说明

## 目录组织

日常入口是 `媒体库/首页.md`。作品类型浏览页、媒体搜索与合集索引集中在 `媒体库/导航/`；说明文档保存在 `媒体库/说明/`。

作品笔记统一放在 `媒体库/作品/`，封面和横幅分别放在其中的 `封面/`、`横幅/` 子目录；合集笔记及其素材统一放在 `媒体库/合集/`。分类由 `media_type` 决定，不按类型拆分作品目录。

`媒体库/模板/` 保存录入模板，`媒体库/视图/` 保存页面组件，Bases 管理视图集中在 `媒体库/视图/数据表/`。从旧版本升级时，请先阅读仓库 `README.md` 的升级说明并备份自己的作品与记录。

## 第一次使用

1. 使用桌面版 Obsidian 打开整个模板文件夹，不要只导入 `媒体库` 子文件夹。
2. 在“设置 → 第三方插件”中关闭安全模式，然后安装并启用 Dataview、Meta Bind、QuickAdd。Homepage、Douban、Style Settings 为推荐或可选插件。
3. 在 Dataview 设置中确认 `Enable JavaScript Queries` 已开启。
4. 在“设置 → 外观”中启用 `media-library` CSS 片段。安装 Border 主题可获得与示例最接近的视觉效果。
5. 返回 [[媒体库/首页|媒体库首页]]。若页面尚未渲染，重启 Obsidian 或执行“重新加载应用”。

完整安装清单见仓库根目录的 `README.md` 与 `THIRD_PARTY.md`。

## 日常使用

首页右上角的外观选择器提供“跟随 Obsidian”、“日间”和“夜间”三种模式。选择会为当前仓库保存，并同时应用到首页、分类、搜索、回顾、作品、合集和体验记录页。“跟随 Obsidian”会在 Obsidian 外观变化时同步更新；固定为日间或夜间时，只改变媒体库页面，不强制修改 Obsidian 外壳。

从 [[媒体库/首页|媒体库首页]] 点击“新增作品”，再选择分类和录入方式；在图书、电影等分类页点击新增时，会直接进入当前分类的录入方式：

- “管理作品类型”可以启用或停用图书、电影、电视剧、动漫、游戏、综艺和纪录片。默认启用前五类；停用只隐藏新增入口和首页分类，不会删除或修改已有作品。
- 综艺和纪录片仍使用豆瓣影视搜索。豆瓣按电影条目导入时使用时长，按电视剧条目导入时使用集数；导入完成后会自动保留你选择的作品类型。

- 豆瓣导入：适合全部七类作品。动漫、综艺、纪录片与豆瓣误分类条目导入后，可在详情页用标题旁的铅笔图标校正作品类型和作品形式。
- 手动新增：标题必填，发行年份可以留空，页面会显示“未知年份”。没有封面、总页数或总集数也不影响展示。
- 新建合集：类型只分为“系列”和“合集”。建立后，在作品详情页设置 `series` 或 `collections` 即可自动收录。

作品页标题右侧的铅笔图标可以直接修改作品名、作品类型、发行日期、类型标签、豆瓣评分以及当前记录方式的专属字段。综艺和纪录片还可以在这里切换“单部（按时长）”或“剧集（按集数）”。个人评分、状态、进度、日期和关系仍使用作品页上原有的专用控件。

首页顶部的“搜索作品”主操作会打开整个媒体库的搜索页。搜索以作品为单位，可以同时匹配标题、原名、别名、作者、导演、演员、题材、系列、合集、平台和发行年份；多个关键词使用空格分隔，作品需要同时包含这些线索。合集关键词按作品的实际归属搜索，既包含作品直接加入的合集，也包含作品通过系列继承的合集。还可以按媒体类型、当前状态、个人评分和收藏标记继续筛选。历史体验记录不会作为重复结果出现，需要从作品详情页查看。

首页顶部的“回顾”按年份汇总已经确认年份的体验记录。体验次数与作品数分开计算，重看、重玩和重读会各自增加一次体验；完成和弃置按记录结果统计，当前仍在进行的作品单独展示，不会混入完成量。月份时间线只使用精确日期，只有年份的记录仍计入年度总数，但归入“月份未知”。一条体验只归入结束年份；开始和结束不在同一年时，系统自动显示“跨年完成”或“跨年弃置”，不要求手工拆分，也不会在多个年度重复统计。电影时长、剧集集数、图书页数和游戏数量作为“完成规模”分别展示，不跨单位相加。完整记录可以按月份、媒体类型、结果和本次评分筛选。

从 1.2 或更早版本升级时，旧作品不会因为打开页面而自动伪造历史日期。请按仓库 `README.md` 的 1.3 升级说明检查已有的已完成、弃置作品；日期不确定的旧记录应保留为迁移记录，确认年份后再纳入年度回顾。日常发现日期或评分有误时，直接打开对应体验记录修改。

从作品页打开某一次体验记录，可以直接查看这次体验的结果、日期、评分、结束进度、版本、游玩平台和日期可信度。点击“编辑记录”可以纠正这些字段。当前次数的作品与记录会双向同步状态、评分和进度；选择“精确日期”时还会同步具体日期，“只确认年份”不会反推作品日期。点击“开始重看 / 重玩 / 重读”后，上一条记录冻结，之后的修改只影响新的当前次数。

同名文件出现冲突时选择保留现有文件，不要用豆瓣结果覆盖已经写好的进度和关系。需要重新导入时，建议先用豆瓣 ID 区分文件名。

## 关系约定

- `series`：第一季、第二季、前传、续作等有关联的作品；系列页默认按 `release_date` 排列。
- 系列笔记中的 `collections`：表示这个完整系列所属的合集；合集会自动继承系列内的作品并去重。
- 作品笔记中的 `collections`：只记录作品直接加入的合集；一个作品可以加入多个合集，与是否属于系列无关。
- `related`：改编、衍生、相似或其他松散关系。

合集的实际成员始终按“作品直接加入 + 合集所含系列的全部作品”计算，重复作品只显示一次。在作品页更换或清除系列时，通过系列继承的合集会立即跟着变化，作品直接加入的合集保持不变。

作品关系区会分别显示“系列继承”和“直接加入”。继承项是只读结果，需要到合集页通过“管理系列”调整；直接加入项可以在作品页添加或移除。合集页的“直接添加作品”只写入作品自身的 `collections`，“管理系列”只修改系列所属合集，两种操作不会互相转换或暗中推断。

## 数据约定

完整字段定义、空值规则和视图取值依据见 [[媒体库/说明/数据字典|媒体库数据字典]]。涉及字段含义时，以数据字典为准；这里保留日常操作需要知道的规则。

作品统一保存在 `媒体库/作品/`，不要按类型移动文件。分类由 `media_type` 决定：`book`、`tv`、`movie`、`anime`、`game`、`variety`、`documentary`。动画电影与剧场版归入电影，漫画归入图书。

个人评分只写入 `rating`，豆瓣社区评分保留在 `source_rating`。作品封面缓存到 `媒体库/作品/封面/`，合集与系列封面放在 `媒体库/合集/封面/`，避免远程图片失效。

作品页的五星控件支持半星：鼠标在星星上左右移动可预览，点击后保存；手机上点击每颗星的左、右半区选择半星或整星，也可以用方向键每次调整 0.5。已有评分右侧的清除按钮会把 `rating` 恢复为空值。

作品详情页按记录方式使用同一套进度控件：图书和剧集每次增减 1，单部影片每次增减 10 分钟，游戏每次增减 5%；中间数字可直接输入精确值。综艺和纪录片可以是单部或剧集。将状态改为“已完成”时，若总页数、总集数或时长已知，当前进度会自动补满。

首页“正在进行”支持直接调整进度：图书、电视剧和动漫每次增减 1，电影每次增减 10 分钟，游戏每次增减 5%。点击中间的进度数字可以精确输入；总页数、总集数或电影时长缺失时，也可以输入“当前/总数”一并补齐。进度达到总量后，右侧按钮会变为“完成”，点击后才会把状态同步为“已完成”。进行中和已完成列表按最近修改时间排序。

首页调整进度时，若开始日期为空，会补记当天；在首页点击“完成”时，会补记缺失的开始和结束日期，已有日期保持不变。详情页也可以手动编辑或清除日期，状态切换为“进行中”或“已完成”时分别补记缺失的开始或结束日期。日期保存失败时会提示并恢复原值。历史记录不会仅因打开页面而批量补记日期。

首页左侧上半区展示最近加入的五部作品，下半区以同样的竖版卡片展示五部待体验候选；桌面端右侧的正在进行列表会随左侧高度铺满，三类信息可以在同一屏查看。“换一批”会随机更换当前候选，“查看全部”进入与分类页一致的完整作品卡片列表，可继续搜索、筛选、排序或切换列表视图；`.base` 数据表保留在 `媒体库/视图/数据表/`，用于后台数据管理。点击“开始体验”会把作品状态改为“进行中”，在开始日期为空时补记当天，并记录最近活动日期；已有日期和进度不会被覆盖。保存失败时作品会留在原位置并显示提示。

作品详情页会显示当前是第几次阅读、观看或游玩。当前体验标记为“已完成”或“弃置”后，会在 `媒体库/记录/` 生成唯一历史记录；旧作品可以在记录区点击“重试保存”补存第一次记录。历史记录按“作品 + 次数”去重，重复保存只更新同一次，不会制造重复条目。

已完成作品可从记录区点击“开始重读”“开始重看”或“开始重玩”。确认后，系统先保存当前历史，再把次数加一，并清空当前进度和本次日期。直接降低已完成作品的进度属于修正当前这一次：状态恢复为“进行中”、完成日期清空、当前历史快照撤销，次数不会增加。暂停后继续也仍然是同一次体验。

五类数据表的管理视图都提供开始和结束日期列。合集索引默认选择排序后的第一个合集；没有合集时选择第一个系列。

作品页关系区中的“相关作品”是双向关系：在任意一端添加或删除后，另一端的 `related` 会同步更新。请使用关系区内的“相关作品（双向）”按钮操作，不要直接在 Properties 中手改 `related`，否则另一端无法感知这次修改。

作品页会默认从 `cover` 自动生成右侧背景。想使用独立横幅时，把本地图片放入 `媒体库/作品/横幅/`，点击封面下方的“设置横幅”，选图后直接拖动预览图调整显示区域并保存。设置后按钮会变为“调整横幅”，可随时重新调整、换图或移除；移除后会自动恢复封面背景。

## 封面与横幅

- 作品封面：`媒体库/作品/封面/`
- 作品横幅：`媒体库/作品/横幅/`
- 合集或系列封面：`媒体库/合集/封面/`
- 合集或系列横幅：`媒体库/合集/横幅/`

封面建议使用 2:3 竖版图，推荐 1000 × 1500 px；横幅建议使用 16:9 横版图，推荐 1920 × 1080 px。比例比绝对尺寸更重要。作品页会在横幅为空时用封面生成背景，因此横幅不是必填项。公开派生仓库时，请勿提交无权再分发的海报、剧照、图书封面或游戏美术。

## 删除示例数据

仓库内的作品、作者、工作室、出版社、评分、体验记录与说明全部是虚构示例。确认模板能正常渲染后，可删除：

- `媒体库/作品/` 中的示例 Markdown 文件和示例封面；
- `媒体库/合集/` 中的“宇宙漫游”和“星际邮差系列”及其示例封面；
- `媒体库/记录/` 中的全部虚构体验记录。

不要删除 `媒体库/模板/`、`媒体库/视图/`、`媒体库/导航/`、`媒体库/说明/` 和首页。

## 备份与公开发布

Obsidian 笔记是本地文件，模板不会自动替你备份。建议使用 Git、Obsidian Sync 或其他同步工具，但不要让多个同步工具同时接管同一个仓库。公开派生版本前，请检查工作区文件、插件配置、账号信息、真实媒体记录和图片版权。

## 常见问题

### 首页显示代码而不是卡片

确认 Dataview 已启用，并在设置中打开 JavaScript Queries，然后重新加载 Obsidian。

### 评分、状态、日期或关系控件不显示

确认 Meta Bind 已安装并启用。插件升级后可先执行“重新加载应用”。

### “新增作品”按钮没有反应

确认 QuickAdd 已启用，而且 `.obsidian/plugins/quickadd/data.json` 仍存在。若重建过 QuickAdd 配置，需要同步修改首页调用的 choice ID。

### 首页没有自动打开

安装 Homepage，并把首页路径设为 `媒体库/首页`。不安装 Homepage 也可以手动打开或收藏首页。

### 豆瓣导入失败

豆瓣导入依赖第三方网页与插件，不属于模板核心能力。确认 Douban 插件和登录状态后仍失败时，请改用手动模板录入。
