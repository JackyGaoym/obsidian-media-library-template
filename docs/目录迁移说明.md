# 目录迁移说明

此说明适用于使用旧版目录的已有媒体库。全新安装直接使用当前目录，无须迁移。

迁移前备份整个库并等待同步完成。退出 Obsidian 后进行批量文件修改，完成后重新打开，避免运行中的插件把旧配置写回磁盘。请迁移自己的数据，不要用模板里的示例覆盖作品或合集。

| 旧位置 | 新位置 |
| --- | --- |
| `媒体库/附件/封面/` | `媒体库/作品/封面/` |
| `媒体库/附件/横幅/` | `媒体库/作品/横幅/` |
| `媒体库/电影.md` 等五个分类页 | `媒体库/导航/电影.md` 等对应分类页 |
| `媒体库/合集索引.md` | `媒体库/导航/合集索引.md` |
| `媒体库/使用说明.md` | `媒体库/说明/使用说明.md` |
| `媒体库/视图/` 下六个 `.base` 文件 | `媒体库/视图/数据表/` 下同名文件 |
| `媒体库/视图/合集关系索引-v10/`（若存在） | `媒体库/视图/合集关系索引/` |

1. 按表移动文件。新位置已有同名文件时先比较内容，不要直接覆盖。附件目录确认没有剩余文件后再移除。
2. 更新现有作品的 `cover`、`backdrop` 和图片链接，以及作品正文与录入模板里的 `imageSuggester(optionQuery(...))` 路径。普通文本和代码中的路径不能依赖 Obsidian 自动更新。
3. 更新首页的分类跳转、合集索引、使用说明及“查看全部”链接；更新 `dv.view(...)` 和其他 `.base` 引用。保留分类页的原文件名，因为类别组件通过文件名识别媒体类型。
4. 在豆瓣插件配置中将 `attachmentPath` 改为 `媒体库/作品/封面`。检查书签和工作区保存的旧路径。QuickAdd 的作品保存目录仍为 `媒体库/作品`，模板目录仍为 `媒体库/模板`；Homepage 仍指向 `媒体库/首页`。
5. 旧合集视图先检查引用，再归档到运行目录以外；当前版本使用稳定名称，避免日后升级反复修改入口。
6. 重新打开库，检查首页、五类导航、合集索引、作品封面与横幅选择器。试建一条作品，确认笔记与导入图片进入新目录，检查完删除测试记录。

作品和合集继续分别使用 `note_type: media` 与 `note_type: media_collection`。分类依赖 `media_type`，不需要按媒体类型再拆作品文件夹。
